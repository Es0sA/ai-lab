Tool Setup & AI Foundations

Learning Objectives

  • Install KNIME Analytics Platform on Windows 10
  • Install and configure n8n locally
  • Create a free Flowise account for RAG and agent workflows later
  • Understand the role of each tool in the program before touching data
Downloads & Installs
KNIME Analytics Platform Tool
Download: knime.com/download — Choose the Windows 64-bit installer
Used from Week 3 to Week 5 for all classical ML workflows (clustering, regression, classification). Free, open-source, no account required.
n8n (Self-Hosted Desktop App) Tool
Download: n8n.io/download — Choose the Windows Desktop App (no server setup needed)
Used from Week 8 onwards to automate workflows. Connects your AI outputs to email, Slack, spreadsheets, and APIs visually.
Flowise (Visual RAG & Agent Builder) Tool
Cloud: flowiseai.com — Sign up for a free account. No install needed.
Used from Week 9 onwards. This is the primary no-code tool for building RAG pipelines and AI agents visually.
Groq Free API Key (LLM access) Tool
Sign up: console.groq.com — 100% free, no credit card required
Groq provides free access to Llama 3 and Mixtral LLMs at very high speed. You will connect Flowise and n8n to Groq so you never need to pay for an LLM API.
